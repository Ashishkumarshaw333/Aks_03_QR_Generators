# QR Code Generator

A simple Python program for generating QR codes.
It asks the user to enter a URL.
The URL is converted into a QR code image.
The generated image is saved as `qrcode.png`.
The program prints a success message after saving.
## Features
- Accepts any URL or text input.
- Removes extra spaces from the input.
- Creates a QR code automatically.
- Saves the image locally.
## Requirements
- Python 3 installed.
- The `qrcode` package installed.
## Installation
`pip install qrcode[pil]`
## Usage
Run `python main.py` and enter your URL.
